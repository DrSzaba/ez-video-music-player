How to install

  1. Click Download for Windows above and save the zip file.
  2. Right-click the zip → Extract All, then double-click EZ-Video-Music-Player-Setup.exe.
  3. Click Next → Install → Finish. It’s in your Start menu and on your desktop. (It replaces an older version and keeps your settings.)
Seeing a blue “Windows protected your PC” box? That’s Windows being careful with any new program from a small maker. Click More info, then Run anyway. No administrator password and nothing else to install.

Questions

Does it send my information anywhere?

No. There’s no account, no ads and no tracking. The only time it goes online is to check GitHub for a new version of the player (and when you open an internet stream).

How do I open my files with it?

Right-click any video or music file → Open with → EZ Video/Music Player. To make it your main player: Settings → Apps → Default apps.

How do I see which version I have?

Start menu → EZ Video/Music Player – About and Updates. Click Check for updates to look right away.

Does it work on a phone or Mac?

Not yet — it’s for Windows 10 and 11 (64-bit).

How do I remove it?

Settings → Apps → Installed apps → EZ Video/Music Player → Uninstall.
